Sorting & Searching Algorithm Visualizer

An interactive Python application to visualize popular sorting and searching algorithms. Built with Tkinter for the GUI and Matplotlib for real-time animations, this tool lets you compare algorithms side by side while tracking their execution time.

Features
Visualize multiple algorithms simultaneously.
Supported algorithms:
Bubble Sort
Merge Sort
Quick Sort
Linear Search
LSD Radix Sort
MSD Radix Sort
Real-time execution time tracking for each algorithm.
Highlighted steps to show comparisons, swaps, and progress.
Generate random arrays or input custom arrays.
Interactive GUI with easy selection of algorithms.

Installation
Clone the repository:
git clone https://github.com/yourusername/algorithm-visualizer.git
cd algorithm-visualizer

Install dependencies:
pip install matplotlib

(Tkinter comes pre-installed with Python on most systems. If not, install it separately.)
Usage
Run the application:
python main.py

Enter an array size to generate a random array, or provide a custom array (comma-separated).
Select the algorithms you want to visualize.
(Optional) Enter a target value if using Linear Search.
Click Start to watch the visualization and compare performance.
Example
Input: 10 (array size)
Algorithms: Bubble Sort, Merge Sort, Quick Sort
Output: Animated side-by-side comparison with time taken for each algorithm.
